    How recovery works here

    The ALB health-checks /health on each instance and routes only to healthy targets. When an instance is terminated, the target group removes it from rotation and the remaining instance(s) keep serving. The Auto Scaling Group sees capacity below its desired count and launches a new instance with a new ID. Terminated instances never come back, so the dashboard has no reset that restores them.

    State comes from the AWS APIs (Auto Scaling, ELBv2, EC2) through a read-only instance role. Instance identity comes from EC2 metadata (IMDSv2).
